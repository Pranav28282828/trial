# Project Introduction

## AGENT AI — AI-Based Early Student Success & Placement Intelligence Platform

**AGENT AI** is an AI-based student success and placement intelligence platform developed to analyse academic and employability-related student attributes and provide data-driven insights into placement readiness.

The platform uses **Machine Learning** to predict student placement status and identify potential risk factors, weaknesses, intervention priorities, and areas requiring improvement. It also integrates **Generative AI** through the **Groq API and GPT-OSS** to provide personalized career guidance.

### Major Application Modules

- **Student Prediction**
- **Student Dashboard**
- **Early Intervention**
- **AI Career Advisor**
- **Model Information**

### Technologies Used

| Category | Technologies |
|---|---|
| Programming | Python |
| Data Analysis | Pandas, NumPy |
| Machine Learning | Scikit-learn, Random Forest Classifier |
| Application Development | Streamlit |
| Generative AI | Groq API, GPT-OSS |
| Development Environment | Jupyter Notebook |
| Version Control | Git, GitHub |
| Data Processing | CSV / Pandas DataFrames |

### Model Configuration

The project uses a **Random Forest Classifier** for placement-status prediction.

- `n_estimators = 300`
- `max_depth = 12`
- `min_samples_split = 5`
- `min_samples_leaf = 2`
- `max_features = "sqrt"`
- `class_weight = "balanced"`
- `random_state = 42`

The prediction target is **`placement_status`**. Identifiers and direct outcome-related information such as **`student_id`** and **`salary_package_lpa`** are excluded from model inputs.

**Evaluation results:** Accuracy 55.57%, ROC-AUC 0.5772 on a held-out 20,000-record test split (80/20 stratified split, `random_state = 42`). See the full evaluation notebook and project report for the complete classification report, confusion matrix, and feature-importance breakdown.
